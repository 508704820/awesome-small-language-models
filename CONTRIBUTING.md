# Contributing to awesome-small-language-models

Thanks for contributing to this curated list of small language models!

## Adding a New Entry

1. **Fork** this repository
2. **Add your entry** in alphabetical order within the appropriate section
3. **Format**: `- [Model Name](URL) — Brief description. [Parameters] [License]`
4. **Submit a PR** with a clear title

## Guidelines

- Entry must be a small language model (typically <10B parameters)
- Include parameter count when possible (e.g., 1.5B, 7B)
- Include license info (MIT, Apache, GPL, Commercial, etc.)
- Verify all links work (no 404s)
- Keep descriptions under 100 characters
- No duplicates
- One entry per PR preferred

## Sections

| Section | Content |
|---------|---------|
| Models | SLMs organized by parameter count |
| Frameworks | Training, fine-tuning, inference tools |
| Datasets | Small-model training data |
| Benchmarks | Evaluation frameworks |
| Papers | Key SLM research |
| Resources | Tutorials, guides, blogs |

## Quality Checklist

- [ ] Link is reachable
- [ ] Description is accurate
- [ ] Correct section
- [ ] Alphabetical order
- [ ] Parameter count and license included
- [ ] Not a duplicate

## Code of Conduct

Be respectful. No spam or low-quality submissions.
